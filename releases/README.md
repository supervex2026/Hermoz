# Hermoz Releases

This directory contains standalone release builds and setup installers for Hermoz.

## Latest Release: v2.4 (Hermoz Desktop v0.1.0)

- **Installer**: `Hermoz_0.1.0_x64-setup.exe` (5.85 MB)
- **Platform**: Windows 10 / 11 (x86_64)
- **Hardware Profile**: Optimized for lightweight desktop environments (Intel HD Graphics 530, 4GB RAM, zero Chromium overhead).

### Highlights
- **Design System**: Instrument-grade cool slate-sapphire OKLCH token ramp with compact desktop density.
- **UI Chrome**: 100% vector Lucide icons replacing all legacy emoji in UI chrome.
- **Companion Modes**: Dual-mode floating companion overlay with click/hover states and full two-pane dashboard.
- **Autonomous Agent Workspace**: Local command execution, file tree, web research, and security approval checkpoints.
- **AI Routing**: Multi-provider failover across Gemini 3.6 Flash, Groq GPT-OSS 120B, and OpenRouter.
- **Screen & Voice**: Real-time desktop screen inspection (Alt+S) and Push-to-Talk voice engine (F1).
